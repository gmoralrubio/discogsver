# External Providers and Caching

Read when changing external-provider integrations or caching. The backend currently contains only a temporary Discogs OAuth 1.0a proof for one authenticated, read-only search; see [the proof guide](../discogs-oauth.md). Provider choices beyond that proof, contracts, data handling, and cache behavior are not currently product decisions; confirm requirements with the user and consult current official provider documentation before implementation.

See [product](product.md) for scope guidance and [security](security.md) before handling credentials or external side effects.
